# 🏮 詩境遊 (Poetry Journey)

歡迎來到《詩境遊》！這是一款結合古典文學與互動探索的沉浸式網頁遊戲。在這裡，你將遠離喧囂，透過視覺、聽覺與互動，重新感受傳統詩詞的唯美意境。

## 🎮 玩法指南

本遊戲無需下載，打開網頁即可開始你的文學之旅。請嘗試以下互動體驗：

*   **✨ 光點遊戲（尋覓詩意）**
    畫面中會隱藏著閃爍的光點，這些光點是詩詞意境的化身。透過滑鼠點擊（或手機觸控）捕捉這些光點，即可逐步揭開詩詞的面紗。遊戲下方的列表更可查看每個意象的廣東話翻譯及意思，幫助你理解古文。
*   **📖 閱讀全文（品味經典）**
    無需解鎖詩詞，你即可展開「閱讀全文」模式。在沒有任何干擾的清幽排版下，靜下心來細細品味每一句詩詞的遣詞用字與深遠意涵。
*   **🎵 語音朗讀（聲臨其境）**
    除了文字之外，聽覺也是詩境的一部分。點擊「朗讀」按鈕，即可聆聽專業的聲效朗讀。如在遊戲關卡中收聽，更可搭配背景的國風音效，讓你彷彿置身於詩人當下的時空。
*   **💮 收集印章（成就收集）**
    在你的文學旅程中，每一次的探索與閱讀都不會留白。達成特定條件後，你將在成就介面上獲得專屬的「數位印章」。快來收集所有充滿國風設計感的印章吧！
